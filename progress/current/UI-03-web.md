- T12, **desviación de D10/R12**: no se usa `lazy` de React Router. Se usa `lazyFeatureRoutes` (app/router/lazyFeature.tsx): camino y título estáticos (`features/*/pages.ts`), y el elemento descarga la feature con `import()` al renderizarse tras `RequireRole`. Un primer intento con `use()` + `Suspense` se quedaba en «Cargando» al navegar entre fragmentos; se sustituyó por estado explícito (`FeatureLoader.settled`). «Reintentar» vuelve a pedir el código (sin recargar el documento).
